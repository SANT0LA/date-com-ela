# Date Amanhã com João

Um aplicativo web interativo e divertido para escolher o local do seu date amanhã com João! 🎉

## Descrição

Este é um app simples feito em HTML, CSS e JavaScript puro que simula uma conversa engraçada para confirmar um date e escolher um restaurante através de uma roleta animada. Inclui efeitos visuais, sons e animações para tornar a experiência mais divertida.

## Como usar

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` em qualquer navegador web moderno.
3. Clique nos botões para navegar pelas telas e interagir com o app.

## Funcionalidades

- **Tela de confirmação**: Botões "CLARO!" e "Não." (o "Não." foge do mouse!).
- **Tela de empolgação**: Confirma se está empolgada, com botão explosivo para "Não.".
- **Roleta de restaurantes**: Gire a roleta para escolher um restaurante aleatoriamente ou selecione manualmente.
- **Tela final**: Celebração com chuva de emojis e som.
- **Reiniciar**: Botão para voltar ao início.

## Personalização

Edite as configurações no topo do arquivo `index.html`:

```javascript
const NOME    = "Teté";  // Nome da pessoa
const HORARIO = "19 horas";  // Horário do date
const restaurants = [
  "Açougue","Al Mare","Purgatorio","Lotti","Cantina Volpi",
  "33 Contemporâneo","Ori","Casa Iryna","Amado","GAttai","Alfedo"
];  // Lista de restaurantes
```

Você pode alterar cores, fontes, sons e animações editando o CSS e JavaScript no arquivo.

## Tecnologias

- **HTML5**: Estrutura da página.
- **CSS3**: Estilos e animações.
- **JavaScript (ES6+)**: Lógica interativa, incluindo Web Audio API para sons.
